Production AI Architectures

Two-stage decoupled deep vision architecture designed for zero-license risk commercial deployment.

Stage 1: Detection Champion Apache 2.0

RTMDet-Tiny (CSPNeXt + PAFPN)

High-efficiency single-stage real-time object detector optimized for document micro-strokes and signatures with extreme aspect ratios. Avoids the AGPL viral copyleft of Ultralytics completely.

Backbone:CSPNeXt-Tiny
Neck:CSPNeXtPAFPN Multi-scale
Head:RTMDetSepBNHead
Parameters:4.8 Million
Input Size:640 × 640 Dynamic Tile
Stage 2: Verification Champion BSD-3-Clause

Siamese ResNet-50 Metric Extractor

Deep Siamese convolutional neural network with twin shared weights and Contrastive Loss optimization. Encodes raw signature crops into a 256-dimensional unit hypersphere where genuine pairs cluster with cosine distance near 1.0.

Architecture:ResNet-50 Siamese Twin
Embedding Space:256-D L2-Normalized
Loss Function:Contrastive Loss (Margin = 1.0)
Parameters:25.6 Million
Metric Measure:Cosine Similarity

Calibrated Decision Policy

✅ GENUINE (Score ≥ 0.82)

High biometric confidence. Stroke pressure, curvature, and aspect-ratio alignment strongly match authentic references.

⚠️ MANUAL REVIEW (0.65 ≤ Score < 0.82)

Borderline similarity. Inconclusive variation or mild tremor. Routed to compliance officer for human forensic review.

❌ FORGED (Score < 0.65)

High forgery probability. Significant divergence in cosine embedding distance across stroke topology.

Google Colab GPU & MLOps Retraining Hub

Trigger GPU training runs on your 28,000-image dataset and automate MLOps deployment.

1. Run GPU Training in Google Colab

In your connected Google Colab notebook, execute the following commands to pull the latest code and train the detection and verification models on the Tesla T4 GPU: 

# Pull latest repository code
%cd /content/sign-detect-verify
!git pull origin main

# Option A: Train Detection Model on Tesla T4 GPU (Zero Comet API key needed)
!python training/detection/train_rtdetr.py --epochs 10 --batch-size 8 --tracker none

# Option B: Train Siamese Verification Model on GPU
!python training/verification/train_resnet50.py --epochs 10 --batch-size 16 --tracker none

2. Automated Hugging Face Webhook Ingestion

When new signature images are committed to Hugging Face Datasets, the webhook event hits /api/v1/webhooks/huggingface with an HMAC-SHA256 signature, dispatching a retraining job to Celery. 

# Test Webhook Trigger via curl:
curl -X POST "http://localhost:8000/api/v1/webhooks/huggingface" \
  -H "Content-Type: application/json" \
  -H "X-Webhook-Secret: default_hf_secret_change_in_production" \
  -d '{"event": "dataset.update", "repo_id": "Mels22/Signature-Detection-Verification"}'
