Deep Neural Vision Architecture

Decoupled Two-Stage Model Pipeline

Industrial machine learning architecture built to strictly respect commercial licenses and avoid AGPL-3.0 viral copyleft.

Stage 1: Detection Apache 2.0 / BSD-3

RTMDet-Tiny / Faster R-CNN FPN

High-efficiency single-stage real-time object detector optimized for document micro-strokes, seals, and signatures with extreme aspect ratios. Avoids the AGPL viral copyleft of Ultralytics completely.

Backbone:CSPNeXt-Tiny / ResNet-50
Feature Pyramids:PAFPN Multi-scale P3-P5
IoU Post-Processing:NMS threshold = 0.25
Parameters:4.8 M (Tiny) / 41.5 M (R50)
Input Tile:640 × 640 Dynamic Resize
Stage 2: Verification BSD-3-Clause

Siamese ResNet-50 Metric Extractor

Deep Siamese convolutional neural network with twin shared weights and Contrastive Loss optimization. Encodes raw signature crops into a 256-dimensional unit hypersphere where genuine pairs cluster with cosine similarity near 1.0.

Architecture:Twin ResNet-50 Backbone
Embedding Space:256-D L2-Normalized
Objective Loss:Contrastive Loss (margin=1.0)
Parameters:25.6 Million
Metric Measure:Cosine Distance (u • v)

Automated MLOps Continuous Retraining Pipeline

The continuous learning system ingests Hugging Face Dataset webhook events via HMAC-SHA256 signature verification, executes unattended training tasks in Celery workers, and enforces an automated Promotion Quality Gate (mAP@50 ≥ 0.85 and EER ≤ 0.08) before pushing SHA-256 versioned artifacts to S3 outside Git.

1. Webhook Ingest HMAC-SHA256 authenticated event triggers Celery task
2. Remote Train Distributed PyTorch training run across GPU nodes
3. Quality Gate Automated validation benchmark evaluation guard
4. Versioned Deploy SHA-256 binary upload to S3 & zero-downtime hot-swap
Production AWS Cloud Topology

AWS Infrastructure & Terraform Architecture

Decoupled enterprise microservice topology provisioned via automated Terraform Infrastructure as Code.

💡 Click architecture diagram to open high-resolution interactive lightbox

ECS Fargate Ingestion API

Stateless FastAPI container running behind AWS Application Load Balancer. Validates multipart payloads, saves originals to S3, and dispatches job IDs to RabbitMQ.

ECS Fargate Celery Workers

Auto-scaling inference workers executing PyTorch detection & verification models. Fully decoupled from client request threads to maintain SLA stability.

Amazon RDS PostgreSQL 16

Multi-AZ relational database storing asynchronous job states, detected bounding boxes, cosine similarity scores, audit trails, and version registry.

Amazon MQ (RabbitMQ)

Managed AMQP message broker with dead-letter exchanges (DLX) providing guaranteed delivery and buffering high document bursts under load.

S3 Artifact & Storage Bucket

Stores input documents, signature crops, and versioned SHA-256 model weights (detector_best.pth, verifier_best.pth) outside Git.

Prometheus & Grafana

Scrapes `/metrics` every 15s to monitor p50/p95/p99 latency percentiles, worker task saturation, and authenticity decision distributions.
